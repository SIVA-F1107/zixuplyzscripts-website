ZixuPlyz website starter
========================

FILES
- index.html: the complete responsive website.

HOW TO CUSTOMIZE ON YOUR PHONE
1. Open index.html in a code/text editor app.
2. Find https://www.youtube.com/ and replace it with your YouTube channel URL.
3. Find the card titled "Community Resource Pack".
4. Replace href="#" on its button with your Google Drive or other direct file-share URL.
5. Change the resource title and description to match your own content.

HOW TO PUBLISH
- Easy static hosting: upload index.html to a static hosting service such as GitHub Pages, Netlify, or Cloudflare Pages.
- This file is a website template, not yet published online. It does not create a live URL automatically.

SAFETY
Only share files you have the right to distribute. Modified game files or skin scripts may violate game rules or pose security risks.
